# Разведчик вакансий

Инструмент, который ищет вакансии, оценивает каждую по моему профилю и объясняет оценку. Написан под собственную задачу: когда откликов больше семидесяти, глазами просматривать выдачу перестаёт работать - взгляд замыливается, и сильные вакансии теряются среди шума.

**Стек:** Python, FastAPI, hh.ru API. Без внешних зависимостей в ядре - только стандартная библиотека.

## Чего он намеренно не делает

**Не отправляет отклики.** Это не техническое ограничение, а решение. Отклик уходит от моего имени реальному работодателю и необратим: повторно откликнуться на ту же вакансию нельзя. Цена ошибки несимметрична - выигрыш измеряется сэкономленными минутами, проигрыш сожжённой вакансией. Инструмент доводит до момента «прочитай и реши», а решение остаётся за человеком.

## Как устроена оценка

Оценка бесполезна без объяснения, поэтому вместе с баллом всегда возвращаются причины.

- **Сильные стороны** - список навыков с весами и подтверждением. Подтверждение попадает и в объяснение, и в черновик письма: не «знаю PostgreSQL», а «хранимые процедуры, оптимизация запросов, замена легаси-процедур».
- **Пробелы** снижают балл, но не отсеивают. Kubernetes в проде, IaC, обучение моделей - встретилось в вакансии, значит честно уменьшаем оценку и говорим об этом в письме.
- **Блокеры** отсеивают сразу. Английский B2 при коммуникации полностью на нём, реверс-инжиниринг, обучение моделей - это не пробел на вечер, а другая профессия.
- **Штрафы за условия.** Вилка ниже планки, сменный график, роль «обучим с нуля» при семи годах опыта, задачи первой линии - всё это снижает балл, даже когда технологии совпадают полностью.

Профиль вынесен в отдельный модуль `scout/profile.py`. Это единственное место, которое нужно править при изменении опыта: скоринг о кандидате ничего не знает.

## Черновик письма

Для каждой неотсеянной вакансии собирается черновик сопроводительного - из подтверждённых фактов профиля под то, что реально требует вакансия, включая честный абзац о пробелах. Это именно черновик: человек дочитывает, правит под компанию и только тогда отправляет.

Форматирования в письме нет намеренно - поле отклика на hh markdown не передаёт, звёздочки уехали бы в письмо как есть.

## Запуск

```bash
pip install -r requirements.txt
uvicorn scout.app:app --port 8100
```

Интерфейс: <http://127.0.0.1:8100/>, документация API: `/docs`.

**Про токен hh.** Анонимный доступ к API hh закрыт - на запросы без токена приходит 403. Токен бесплатный: dev.hh.ru, создать приложение, положить в переменную окружения `HH_TOKEN`. Без токена инструмент работает на демо-наборе и честно говорит об этом баннером.

## Структура

```
scout/
  profile.py   профиль: навыки с весами, пробелы, блокеры, треки
  hh.py        клиент API hh, разбор html-описаний
  scoring.py   оценка и объяснение
  letter.py    черновик сопроводительного
  demo.py      набор вакансий для работы без токена
  app.py       веб-интерфейс и API
templates/
  index.html   одностраничный интерфейс со светлой и тёмной темой
```

## Планы

- Сохранение находок между запусками, чтобы не показывать одно и то же дважды.
- Запуск по расписанию с уведомлением только о сильных матчах.
- Оценка тона вакансии: расплывчатые формулировки и обещания без конкретики - тоже сигнал.
