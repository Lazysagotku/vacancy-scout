# Факты для писем на разработку

Каждый пункт - действие и результат. Без указания, где это было.

## Бэкенд на C#

- Полтора года разработки внутреннего ПО для финансовых процессов: учётные балансы, платежи, проводки.
- Основной объём - пошаговый дебаг и анализ причин ошибок по заявкам пользователей, без документации, исправление.
- TimeReportV3, собственный инструмент учёта заявок: двойная интеграция с тикет-системой и Jira через Dapper, выгрузка KPI в Excel с асинхронной обработкой, push-уведомления о нераспределённых задачах.
- Отчётность: отдельный бэкенд, шаблоны отчётов через Visual Studio.

## Базы данных

- Хранимые процедуры на PostgreSQL и MS SQL, замена громоздких легаси-процедур на компактные и быстрые, сопоставление данных при миграции на новые структуры.
- Оптимизация запросов по планам выполнения, MySQL и PostgreSQL.
- MongoDB на федеральном проекте с данными по всей стране.
- С ORM работал через Dapper, EF Core разбирает на собственном проекте, Django ORM - в своей системе учёта.

## Python

- Перенос заявок из внутренней тикет-системы в Jira: цепочка из шести шагов с проверочным буфером, защита от дублей. Год в проде у всей группы поддержки, руководство импортировало задачи само.
- Автоматизация отчётности: сначала выгрузка, потом конструктор отчётов, которым руководство пользовалось само.
- Электронный секретарь на React и Python: многопоточные сессии, мониторинг через Selenoid, отчёты в Telegram-бот.
- Собственная система учёта техники на Django: 25 полей, Docker.
- Selenium и pandas в рабочих скриптах.

## Интеграции и очереди

- REST и SOAP по чужим контрактам, поиск расхождений данных между сервисами.
- RabbitMQ через PIX Robotics для отслеживания сессий; Kafka для баг-трекинга личного кабинета брокеров и клиентов (портфели, вводы и выводы, вход через Госуслуги).
- Сайтмапы клиентов и биржи переросли в вебхуки; bash-скрипт проверки с email-алертами.
- Postman до Collection Runner, Swagger, SoapUI.

## Поддержка и эксплуатация - коротко, чтобы письмо не отрицало то, что есть

- Семь лет поддержки корпоративных систем на всех линиях, последние годы третья линия: разбор обращений до причины в коде, консультации бизнес-подразделений, передача знаний.
- Мониторинг в Zabbix и Grafana: хосты, триггеры, дашборды. Диагностика по логам через SSH, Postman до Collection Runner.
- Релизы через Jenkins с бэкапом и проверкой, все проекты в Docker.

## Инструменты

- Git ежедневно. Релизы через Jenkins с бэкапом и проверкой через Postman и SQL.
- Docker для всех проектов. Linux в эксплуатации: SSH, логи, cron.
- Jira администрировал: проекты, права, учёт времени, Kanban.
