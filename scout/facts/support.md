# Факты для писем на сопровождение, эксплуатацию, поддержку

Каждый пункт - действие и результат. Без указания, где это было.

## Разработка - коротко, чтобы письмо не отрицало то, что есть

- Полтора года разработки внутреннего ПО на C# для финансовых процессов: пошаговый дебаг чужого кода по заявкам, исправление, хранимые процедуры, собственный инструмент учёта заявок с интеграцией в Jira.
- Поддерживал внутренний веб-ресурс на Angular и TypeScript поверх PostgreSQL: разбирал ошибки фронта и бэка по логам, готовил воспроизведение для разработчиков. Сам этот код не писал.
- Python - рабочий инструмент семь лет: интеграции, автоматизация, скрипты, Django.

## Поддержка и инциденты

- Работал на всех линиях: принимал и распределял заявки, консультировал пользователей напрямую, объяснял непрофильным сотрудникам на их языке, расследовал инциденты и закрывал сам.
- Последние годы - третья линия: разбирал сложные обращения, которые не смогли закрыть первая и вторая, консультировал бизнес-подразделения, передавал знания коллегам.
- Готовил шаги воспроизведения ошибок для разработчиков на аутсорсе: расследовал, описывал, передавал, принимал исправление.
- Построил собственную тикет-систему, после которой отдельная первая линия стала не нужна.
- Сверял балансы, платежи и проводки между системой и выгрузками: суммы обязаны сходиться, расхождение - инцидент.

## Мониторинг

- Мониторинг серверов в Zabbix, затем переход на Grafana: настраивал хосты, триггеры, графики, переносил дашборды.
- Отслеживал нагрузку серверов под окна бэкапов.
- Bash-скрипт с циклом проверки всех сайтмапов клиентов и биржи, wget с user-agent, email-алерты при несостыковках.

## Диагностика

- Логи через WinSCP и SSH, Postman до Collection Runner (массовые запросы по списку ID), Swagger, SoapUI.
- Кейс: HTTP 418 в Postman оказывался Broken Pipe в логах Cassandra - ошибка на клиенте, причина на сервере.
- Оптимизация запросов на MySQL и PostgreSQL по планам выполнения.

## Релизы и эксплуатация

- Релизы через Jenkins: ID сборки от разработчиков, бэкап старой версии, загрузка новой, проверка через Postman и SQL-запросы.
- Docker: все проекты в контейнерах - образы, старт, стоп, рестарт при обновлениях.
- Linux в эксплуатации: SSH, логи, cron.
- IBM FileNet: контроль версий документов.
- Jira: участвовал во внедрении, потом администрировал - проекты, права, учёт времени, Kanban, экспорт для аналитиков.

## Автоматизация рутины

- Перенос заявок из внутренней тикет-системы в Jira на Python: цепочка из шести шагов с проверочным буфером, защита от дублей. Год в проде у всей группы поддержки, руководство импортировало задачи само.
- Автоматизировал отчётность по расчёту аэротерриторий на Python: сначала выгрузку, потом конструктор отчётов, которым руководство пользовалось само.
- Электронный секретарь на React и Python: многопоточные сессии, мониторинг через Selenoid, отчёты в Telegram-бот.
- Selenium-автоматизация рутины по запросам коллег, pandas для выгрузок и сверок.

## Интеграции и данные

- REST и SOAP по чужим контрактам, поиск расхождений данных между сервисами.
- Сайтмапы клиентов и биржи переросли в вебхуки.
- RabbitMQ через PIX Robotics для отслеживания сессий; Kafka для баг-трекинга личного кабинета брокеров и клиентов (портфели, вводы и выводы, вход через Госуслуги).
- PostgreSQL, частично Oracle, MS SQL, MySQL, MongoDB на федеральном проекте с данными по всей стране.
- Хранимые процедуры на PostgreSQL и MS SQL, замена громоздких легаси-процедур на компактные, сопоставление данных при миграции на новые структуры.
